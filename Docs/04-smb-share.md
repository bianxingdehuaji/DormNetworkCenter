# 04. 局域网文件共享与协同 (Local-Share)

> 💡 **核心架构说明**：受限于小米 CR6608 的 Flash 空间（128MB）与缺少物理 USB 扩展口的物理特性，本方案采用**以宿舍主力 Windows 11 PC 作为核心 SMB 存储宿主**，OpenWrt 路由器作为**静态 IP 锚定与局域网路由枢纽**的拓扑架构。MacBook、iPhone 等无线终端实现跨平台全速互联，同时路由器可按需挂载 PC 存储实现日志归档。

在宿舍多设备协同场景中，Windows PC、Mac 笔记本与 iPhone 之间传输学习资料、代码包或影音文件通常高度依赖外部公网即时通讯软件，不仅占用外网带宽、受制于传输限速，且存在数据被压缩与隐私风险。

本节详细介绍如何以 Windows 11 PC 为核心搭建原生 SMB 共享中心，并通过 OpenWrt 路由器完成局域网静态绑定与协同交互。

---

## 一、方案架构与网络拓扑

```text
┌──────────────────────────────────────────────────────────┐
│                   OpenWrt 边缘网关 (CR6608)              │
│  - DHCP 静态租约绑定 (分配固定 IP: 192.168.1.100)        │
│  - 本地域名解析 (dorm-pc.lan)                            │
│  - Wi-Fi 6 / 千兆硬件交换网络                            │
└─────────────┬──────────────────────────────┬─────────────┘
              │ (千兆双绞线直连 LAN 口)       │ (Wi-Fi 6 5GHz 无线回传)
              ▼                              ▼
┌───────────────────────────┐  ┌───────────────────────────┐
│   Windows 11 PC (核心宿主) │  │  移动终端 (MacBook / iOS) │
│ - 原生 SMB 3.0 高性能协议栈│  │ - 跨生态原生免客户端接入  │
│ - 大容量 NVMe/SATA 本地存储│  │ - 局域网极速互传与流媒体串流│
└───────────────────────────┘  └───────────────────────────┘
```

该架构的优势：
1. **充分发挥硬件特长**：避免了在路由器受限 Flash 内进行频繁小文件 I/O 导致的闪存损耗，直接利用 PC 的高速大容量硬盘。
2. **千兆与 Wi-Fi 6 满速互传**：PC 与路由器有线千兆直连，Mac/iPhone 通过 5GHz Wi-Fi 6 访问 PC，局域网握手速率跑满，互传速度可达 100~115 MB/s。
3. **低功耗与按需扩展**：路由器自身几乎零负载，内存占用不受任何影响。

## 二、路由器端配置：锁定 Windows PC 静态 IP

为避免 Windows PC 重启或网卡断连后局域网 IP 发生漂移，导致各终端映射失效，需在 OpenWrt 网关中将 PC 的 MAC 地址与固定 IP 进行租约绑定。

1. 打开浏览器登录 OpenWrt 管理后台（默认 `http://192.168.1.1`）。
2. 进入导航菜单：**网络 (Network)** $\to$ **DHCP/DNS** $\to$ 下拉至 **静态地址分配 (Static Leases)**。
3. 点击 **添加 (Add)** 并填写：
   * **主机名 (Hostname)**：`Dorm-PC`
   * **MAC 地址 (MAC-Address)**：下拉选择 Windows PC 有线网卡的 MAC 地址。
   * **IPv4-地址 (IPv4-Address)**：指定固定内网 IP（例如 `192.168.1.100`）。
   * **租期 (Lease time)**：设置为 `24h` 或 `infinite`。
4. 点击 **保存并应用 (Save & Apply)**。

## 三、Windows 11 PC 端：配置原生 SMB 共享

### 3.1 切换为“专用网络”
Windows 11 默认的“公用网络”防火墙策略会自动丢弃入站的 SMB 请求，因此必须切换网络配置文件：
1. 打开 Windows **设置** $\to$ **网络和 Internet** $\to$ **以太网**。
2. 将 **网络配置文件类型** 从“公用网络”修改为 **“专用网络”**。

### 3.2 启用专用网络高级共享
1. 打开 **控制面板** $\to$ **网络和共享中心** $\to$ 点击左侧 **更改高级共享设置**。
2. 展开 **专用网络** 区域：
   * 勾选 **启用网络发现**。
   * 勾选 **启用文件和打印机共享**。
3. 展开 **所有网络** 区域：
   * 建议保持 **启用密码保护的共享**（保护宿舍局域网数据隐私）。

### 3.3 创建共享目录并设置读写权限
1. 在 PC 大容量磁盘（如 D 盘）新建共享文件夹（如 `D:\DormShare`）。
2. 右键该文件夹 $\to$ **属性** $\to$ 切换至 **共享 (Sharing)** 选项卡。
3. 点击 **高级共享 (Advanced Sharing)**：
   * 勾选 **共享此文件夹**。
   * 共享名称填入 `DormShare`。
   * 点击 **权限 (Permissions)**：选中当前用户（或单独创建的专用共享账户），勾选 **完全控制** 与 **读取** 权限，点击确定。
4. 切换到 **安全 (Security)** 选项卡，确认该账户拥有对应的 NTFS 文件系统写入权限。

## 四、全平台跨生态终端原生接入

由于采用标准 SMB 协议，所有连入路由器同一局域网的终端设备均可使用原生系统组件直连，无需安装第三方传输客户端。

### 4.1 Apple Silicon MacBook (macOS)
1. 打开 **访达 (Finder)**。
2. 按快捷键 `Cmd + K`，或点击顶部菜单栏 **前往 (Go)** $\to$ **连接服务器 (Connect to Server...)**。
3. 在服务器地址栏输入：
   ```text
   smb://192.168.1.100/DormShare
   ```
4. 连接身份选择 **注册用户**，输入 Windows 系统的用户名与登录密码。
5. 连接成功后，该共享盘将挂载于访达侧边栏，支持直接拖拽传输与实时播放 PC 中的音视频。

### 4.2 iPhone (iOS)
1. 打开 iOS 自带的 **文件 (Files)** App。
2. 点击右上角 **“...” (更多)** 菜单按钮 $\to$ 选择 **连接服务器 (Connect to Server)**。
3. 服务器地址输入：`192.168.1.100` 并点击右上角“连接”。
4. 身份选择 **注册用户**，输入 Windows PC 的账号与密码。
5. 连接完成后即可在 iPhone 端浏览 PC 文件、直接保存微信长文档，或将手机相册的原图/4K 视频直接导出至 PC 硬盘归档。

## 五、进阶联动：OpenWrt 挂载 PC 共享盘（可选）

若后续希望将 OpenWrt 的自动化认证日志（`szu_auth.log`）、路由器配置备份自动同步存储至 PC，可在 OpenWrt 上安装 CIFS 客户端，实现从路由器向 PC 共享盘的双向通信：

```bash
# 1. 安装 CIFS 客户端支持模块
opkg update
opkg install kmod-fs-cifs cifs-utils

# 2. 创建本地挂载目录
mkdir -p /mnt/pc_share

# 3. 挂载 Windows 共享文件夹
mount -t cifs //192.168.1.100/DormShare /mnt/pc_share -o username=Win用户名,password=Win密码,vers=3.0
```

## 六、常见问题与避坑指南 (FAQ)

* **Q1：MacBook 或 iPhone 连接时提示“服务器已关闭或连接超时”？**
  * **检查网络类型**：核对 PC 的网络配置是否为“专用网络”，公用网络会直接屏蔽 445 端口。
  * **验证端口连通性**：在内网其他电脑的 PowerShell 中执行 `Test-NetConnection 192.168.1.100 -Port 445`，确认 TCP 445 端口响应正常。
* **Q2：输入 Windows 账号密码后提示凭据无效？**
  * 若 Windows 绑定了微软在线账号（Microsoft Account），用户名请输入对应的**完整邮箱地址**（或在 PC 终端输入 `whoami` 查看本地用户名）；密码必须为微软账户的登录密码，**不可使用 4 位/6 位的 Windows Hello 本地 PIN 码**。
* **Q3：PC 屏幕关闭后无法连接？**
  * 进入 Windows **设置** $\to$ **系统** $\to$ **电源与电池**，将“睡眠”设置为 **从不**，仅允许“关闭屏幕”，保证有线网卡在息屏状态下依然保持千兆待命。
