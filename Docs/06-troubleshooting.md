## 一、底层与刷机救砖类故障

### 1.1 无法进入 Breed / pb-boot 网页恢复控制台
* **现象**：按住 Reset 键通电后，指示灯闪烁但浏览器访问 `192.168.1.1` 提示无法连接。
* **原因分析**：Bootloader 阶段路由器**不会开启 DHCP 服务**，电脑若处于“自动获取 IP”状态将无法与路由建立通信。
* **解决步骤**：
  1. 拔掉网线，确认网线插在 CR6608 的 **LAN 口**（靠近电源的黄色网口，严禁插蓝色 WAN 口）。
  2. 暂时**禁用电脑的无线 Wi-Fi 网卡**，避免无线网络抢占路由网关。
  3. 打开 Windows 网络设置，将以太网卡手动配置为**静态 IP**：
     * IP 地址：`192.168.1.2`
     * 子网掩码：`255.255.255.0`
     * 默认网关：`192.168.1.1`
  4. 使用无痕/隐私窗口访问 `http://192.168.1.1`（规避浏览器 HSTS 或缓存重定向）。

### 1.2 刷机后 Wi-Fi 信号极弱或缺失
* **现象**：刷入 OpenWrt 后搜索不到 5GHz 信号，或距离路由器 1 米以上即断连。
* **原因分析**：未备份或误格式化了存储无线射频校准参数的 `Factory` 分区（EEPROM 丢失）。
* **解决步骤**：
  * 进入 Breed 控制台，找到 **固件更新 -> EEPROM**，上传刷机前通过 `dd if=/dev/mtd3 of=/tmp/Factory.bin` 导出的原厂 Factory 备份恢复，重启后即可恢复原厂射频功率。

## 二、校园网自动认证与保活故障

### 2.1 脚本执行提示认证成功，但终端依然无法上网
* **现象**：`szu_auth.log` 记录 `result:1`，但电脑或手机打开网页仍跳回 Portal 或显示未连接。
* **排查链路**：
  1. **检查 WAN 口 IP 漂移**：
     校园网服务端校验极其严格，若请求中的 `wlan_user_ip` 与当前分配给路由器 WAN 口的 IP 不一致，将被系统拒绝。
     在 SSH 中执行：
     ```bash
     ubus call network.interface.wan status | grep -A 3 '"ipv4-address"'
     ```
     比对输出的 IP 是否与脚本发出的 `wlan_user_ip` 参数完全一致。
  2. **检查账号并发限制**：
     许多高校限制单个学号同时在线设备数（通常 1~2 台）。若你在手机上直接登录了相同账号，路由器端可能会被强行挤下线。

### 2.2 校园网认证被封禁或出现 503 异常
* **现象**：日志提示账号被锁定或接口返回超时。
* **原因分析**：探针检测频率过高或未配置退避机制，导致因断网连续向校园网鉴权接口高频重试，被学校安全防火墙判定为暴力破解并临时拉黑 MAC。
* **解决措施**：
  * 将 `crontab -e` 中的探活周期调整为 **每 2~3 分钟** 一次：
    ```bash
    */2 * * * * /bin/sh /root/scripts/szu_auth.sh >/dev/null 2>&1
    ```
  * 确保探针 URL 采用轻量且支持 204 无内容响应的接口（如 `http://connect.rom.miui.com/generate_204`），避免消耗不必要的流量。

## 三、代理分流与校园内网冲突故障

### 3.1 开启代理后无法打开校园网认证页与选课系统
* **现象**：开启代理插件后，所有境外网页正常，但内网教务系统（`*.szu.edu.cn`）无法打开，或无法获取验证码。
* **排查链路**：
  1. **CIDR 白名单漏配**：
     进入代理插件的 **直连/白名单 IP**，确保已写入学校私网网段：
     ```text
     172.30.0.0/16
     172.16.0.0/12
     10.0.0.0/8
     ```
  2. **Fake-IP 劫持了内网域名**：
     若代理模式开启了 Fake-IP（虚拟 IP 映射），校园网内网域名会被伪造为 `198.18.x.x`，导致校园内网服务器无法识别来源。
     * **修复方案**：将 DNS 解析模式切换为 **ChinaDNS-NG** 或 **直连优先**，并在“Fake-IP 过滤列表”中追加校园顶级域（如 `*.edu.cn`、`*.szu.edu.cn`）。

### 3.2 节点正常但出现“DNS 泄漏 / 解析超时”
* **现象**：局域网终端频繁出现“正在解析主机”卡顿 3~5 秒后才打开网页。
* **排查链路**：
  在路由器终端执行测试命令：
  ```bash
  nslookup www.baidu.com 127.0.0.1
  nslookup github.com 127.0.0.1
  ```
  若本地 127.0.0.1 响应超时，说明代理插件自带的内部 DNS 转发服务（如 CoreDNS / Dnsmasq 端口）冲突。可检查系统 **网络 -> DHCP/DNS**，确保 DNS 转发端口未被多个插件重复绑定。

## 四、局域网协同 (SMB / RDP) 连接故障

### 四、局域网协同 (SMB / RDP) 连接故障

### 4.1 MacBook / iPhone 提示“找不到服务器”或连接超时
* **排查步骤**：
  1. **确认网络类型**：
     打开 Windows 11 **设置 -> 网络和 Internet -> 以太网**，检查当前网络配置类型：
     * 若为 **“公用网络”**，Windows 防火墙会默认静默丢弃所有入站的 445 (SMB) 与 3389 (RDP) 报文。**必须手动切为“专用网络”**。
  2. **测试端口物理连通**：
     在另一台电脑终端中执行：
     ```powershell
     Test-NetConnection 192.168.1.100 -Port 445   # 测试 SMB
     Test-NetConnection 192.168.1.100 -Port 3389  # 测试 RDP
     ```
     若 `TcpTestSucceeded : False`，说明 Windows 端防火墙规则未正确放行，或 PC 进入了睡眠休眠状态。

### 4.2 远程桌面 (RDP) 提示“用户名或密码错误”但密码确定正确
* **原因分析**：
  Windows 11 默认激活了 **网络级别身份验证 (NLA)**，且不支持直接使用日常在屏幕锁屏界面使用的 4~6 位 PIN 码进行远程凭据协商。
* **修复方法**：
  * **用户名**：若 PC 登录了微软账号，必须输入该账号完整的注册邮箱（如 `user@outlook.com`）；若为离线账户，输入在 `cmd` 中执行 `whoami` 显示的准确账户名。
  * **密码**：必须输入该账户对应的完整密码，**不可输入 Windows Hello PIN 码**。

## 五、硬件资源水位告警 (内存 / 闪存 OOM)

> ⚠️ 小米 CR6608 硬件规格为 **256MB RAM / 128MB Flash**，属于受限嵌入式平台，长期稳定运行的关键在于**避免内存耗尽引发 OOM Killer**。

### 5.1 内存耗尽导致系统死机或自动重启
* **排查方法**：
  在 SSH 中执行：
  ```bash
  free -m
  ```
  观察 `free`（空闲内存）与 `available`（可用内存）。
* **优化策略**：
  1. **精简规则集**：若使用代理插件，切勿勾选全量超大广告规则集（EasyList 等），规则集条目数建议控制在 3 万条以内。
  2. **限制内核内存开销**：在 256MB 内存下，优先选用轻量级核心（如 Sing-box），避免加载内存开销过大的组件。
  3. **开启 Swap 虚拟内存（可选）**：若系统运行大量后台任务，可通过网络或外置存储挂载微型 Swap 文件缓冲内存压力。

### 5.2 Flash 存储空间满导致配置无法保存
* **现象**：修改配置后保存报错，或系统重启后所有新配置丢失。
* **排查方法**：
  在 SSH 中执行：
  ```bash
  df -h /overlay
  ```
  查看 `/overlay` 分区的可用空间。若使用率达到 **100%**，系统将进入只读保护模式。
* **排障与清理**：
  * 检查自愈脚本的日志文件：若长期运行且未做轮转，`szu_auth.log` 会迅速吞噬剩余空间。在 SSH 中直接执行清理：
    ```bash
    cat /dev/null > /root/scripts/szu_auth.log
    ```
  * 清理 `opkg` 产生的临时缓存：
    ```bash
    rm -rf /tmp/opkg-lists/*
    ```

## 六、常用诊断与排错命令速查

| :--- | :--- |
| **实时查看系统内核日志** | `dmesg -w` |
