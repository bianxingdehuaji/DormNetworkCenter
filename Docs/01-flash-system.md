# 01. 底层引导与系统刷入 (Flash & Recovery)

本指南针对小米 CR6608 路由器，演示如何使用提供的本地工具包免拆开启 SSH、备份出厂射频分区、刷入 pb-boot 引导，并最终刷入 OpenWrt 操作系统。

---

⚠️ **注意 / Note**

本节的操作流程与固件底包仅严格适用于 **小米 CR6608** 路由器。请务必确保设备型号一致，其他硬件请勿直接套用，以免导致设备变砖。

**自 02 节起，所有脚本编写、定时巡检逻辑及网络服务配置均基于标准 Linux / OpenWrt 系统环境，具备通用性。**

---

## 一、前期准备与本地资源确认

为了简化流程，所有需要的工具和固件已经为你准备在文件夹中。在操作前，请确保在 Windows 电脑上已经解压并找到了以下两个文件夹：

1. **`Resource` 文件夹**（包含解锁工具与引导底包）：
   * `SSH获取工具`：用于向路由器注入指令，开启后台 SSH 权限。
   * `pb-boot` 固件：路由器不死引导底包（例如 `pb-boot.img`）。
2. **`Resource-固件` 文件夹**（包含操作系统）：
   * `OpenWrt` 系统固件：即将为路由器刷入的最终操作系统镜像。
3. **其他必备软件**：
   * **WinSCP**：图形化文件传输工具（用于固件上传与分区备份）。
   * **Windows 终端 (PowerShell)**：执行 SSH 命令（Win10/11 系统自带）。

---

## 二、环境连接与获取 STOK

1. **物理连接**：
   * 使用网线，一端连接电脑网口，另一端连接 CR6608 的 **LAN 口**（切勿连接蓝色 WAN 口）。
   * 暂时**禁用电脑的 Wi-Fi**，避免局域网 IP 冲突。
2. **登录小米后台并获取 STOK**：
   * 打开浏览器访问 `http://192.168.31.1`，使用背部贴纸上的默认密码登录原厂管理后台。
   * 登录成功后，观察浏览器顶部的地址栏 URL，复制其中的 `stok=` 后面的那一串字符（例如：`stok=abcdef123456/web/home`，其中 `abcdef123456` 就是 STOK）。
   * *注意：复制后请保持该网页打开，切勿刷新或点击登出，否则 STOK 会立即失效。*

---

## 三、使用一键工具开启 SSH 与备份（防砖核心步骤）

> ⚠️ **极其重要**：路由器的 `Factory` 分区内存储有本机的 MAC 地址与无线射频（EEPROM）校准参数。若未备份且发生意外，将导致 Wi-Fi 信号极弱且无法恢复。我们将使用一键工具自动完成备份。

1. **运行一键刷机工具**：
   * 打开本地的 **`Resource`** 文件夹，运行里面的 **`小米CR660X系列路由器刷机工具`**。
2. **设置与连接设备**：
   * 在工具菜单中输入 **`1`** (设置 IP 地址)，如果你的路由器当前 IP 是 `192.168.31.1`，请在此步骤修改正确。
   * 输入 **`2`** (连接到设备 / 开启 SSH)，根据提示可能需要输入前面获取到的 STOK 或管理员密码。工具会自动破解漏洞并开启 SSH。
3. **创建完整备份**：
   * 在工具菜单中输入 **`4`** (创建完整备份)。
   * 工具会自动读取底层的 `Bootloader`、`Bdata` 和 `Factory` 等关键分区，并将它们备份到本地电脑。
   * **验证：** 请务必在本地电脑的对应目录下检查是否成功生成了备份文件，并将它们妥善保存。

---

## 四、使用一键工具刷入 pb-boot (不死引导)

1. **执行一键刷入**：
   * 在工具的主菜单中，直接输入 **`6`** (刷入 pb-boot)。
   * 工具会自动将内置的 `pb-boot` 底包上传到路由器并执行底层刷写。
2. **重启路由器**：
   * 等待屏幕提示刷入成功后，输入 **`9`** (重新启动设备)。
   * *警告：刷写期间严禁拔掉电源或断开网线！*

## 六、通过 pb-boot 刷入 OpenWrt (底包 + 升级包)

由于 OpenWrt 官方针对 NAND 闪存的机制，我们需要先在 pb-boot 刷入过渡底包，然后再通过临时系统刷入正式版 upgrade 包。

### 6.1 进入 pb-boot 恢复控制台
1. 拔掉路由器电源插头。
2. 用牙签顶住路由器背部的 **Reset 键不放**，然后重新插上电源。
3. 保持按压约 5~8 秒，观察前面板指示灯高频交替闪烁后松开。

### 6.2 配置电脑静态 IP
1. 打开 Windows **设置 $\to$ 网络和 Internet $\to$ 以太网**。
2. 将 IPv4 设置改为“手动”，配置如下：
   * **IP 地址**：`192.168.1.2`
   * **子网掩码**：`255.255.255.0`
   * **默认网关**：`192.168.1.1`

### 6.3 刷入过渡底包 (Initramfs)
1. 打开电脑浏览器，访问 pb-boot 控制台地址：`http://192.168.1.1`。
2. 在固件恢复页面，点击 **浏览 / 选择文件**。
3. 选择 `Resource` 文件夹中的 **过渡底包**（带有 `initramfs-kernel` 字样的文件）。
4. 点击 **恢复 / 刷入 (Flash)**，等待写入完成，路由器会自动重启进入临时的 OpenWrt 系统。

### 6.4 刷入正式升级包 (Sysupgrade)
1. 大约 1~2 分钟后，重新刷新浏览器访问 `http://192.168.1.1`（默认无密码或密码为空），进入 OpenWrt 临时管理后台。
2. 在顶部菜单栏导航至：**System (系统) $\to$ Backup / Flash Firmware (备份/升级)**。
3. 滚动到页面底部的 **Flash new firmware image (刷写新固件)** 区域，点击选择文件。
4. 选择 `Resource` 文件夹中的 **正式升级包**（带有 `squashfs-sysupgrade` 字样的文件），点击 **Upload (上传)**。
5. **极其重要：** 在接下来的确认校验页面中，务必**取消勾选 "Keep settings (保留配置)"**，以防止临时系统的配置污染正式系统。
6. 点击 **Proceed (继续)**，等待路由器彻底刷写并最后一次重启。

### 6.5 进入最终系统
1. 将电脑的以太网 IPv4 设置改回 **自动获得 IP 地址 (DHCP)**。
2. 电脑重新获取到 IP 后，在浏览器访问 `http://192.168.1.1`。
3. 看到全新的 OpenWrt 管理界面，即代表底层刷机与系统交付圆满完成！
